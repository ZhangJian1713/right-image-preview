# 键盘快捷键

[English](./keyboard.md) · **中文**

预览内采用固定绑定，不提供自定义配置。overlay 打开时自动聚焦；contained 模式仅在预览获得焦点时响应。
输入框、可编辑区域、输入法组合期间不触发图片快捷键。宿主说明弹窗打开时可设置 `keyboardEnabled={false}`。

| 按键 | 功能 |
| --- | --- |
| `←` / `Q`，`→` / `E` | 上一张、下一张；按住连续浏览扁平列表 |
| `Home` / `End` | 第一张、最后一张 |
| `↑` / `+` / `=` / 小键盘 `+` | 放大一个档位 |
| `↓` / `-` / 小键盘 `-` | 缩小一个档位 |
| `Space` / 小键盘 `0` | clickZoomEnabled 时执行自适应观察循环，否则切换 Fit ↔ 100% |
| 主键盘 `0` / `1` | 适应视口 / 原始比例 100% |
| `R` / `Shift+R` | 顺时针 / 逆时针旋转 90° |
| `Ctrl/⌘+→` / `Ctrl/⌘+←` | 保留的顺时针 / 逆时针旋转绑定 |
| `W/A/S/D` | 向上 / 左 / 下 / 右平移查看 |
| 小键盘 `8/4/2（或5）/6` | 向上 / 左 / 下 / 右查看 |
| 小键盘 `7/9/1/3` | 向左上 / 右上 / 左下 / 右下查看 |
| `Shift+↑/↓/←/→` | 保留的平移绑定 |
| `PageUp` / `PageDown` | 上一组 / 下一组第一张（多组数据） |
| `F` | 切换全屏；存在 fullscreen 适配器时委托宿主 |
| `?` | 调用 onShowShortcuts（若宿主提供） |
| `I` | 切换 EXIF 面板（showExif=true） |
| `Delete` / `Backspace` | 删除当前图（showDelete=true，由宿主执行） |
| `Esc` | 退出已确认的全屏，否则关闭预览 |

平移仅在 Native 缩放且图片超出媒体视口时生效；对角线速度与轴向相同。小键盘按物理 code 识别，
NumLock 关闭时不退化为 Home/End 或主键盘数字。只为连续缩放/平移允许系统 repeat，切图沿用呈现节拍。
单次操作（旋转、全屏、Space、帮助、删除等）忽略 repeat，失焦、隐藏、关闭说明或卸载会释放长按状态。

除表中列出的组合外，不接管 Ctrl/⌘/Alt；尤其不迁移带修饰键的 Space。Space 位于按钮上时保留原生激活行为。
缩放输入提交限制到当前 stops 上限，Enter 确认，Esc 取消。任意有效预览按键会恢复自动渐隐控件。

`getPreviewShortcutHelp({ navigation, groups, exif, delete, shortcuts })` 从实际固定绑定生成只读条目，
宿主可按真实能力隐藏不适用项并翻译 action 标签；没有绑定编辑、配置持久化或设置 UI。

纯 toggle 全屏宿主（如 VS Code）没有可靠全屏状态，因此 Esc 保留关闭预览行为，F/全屏按钮切换窗口。
宿主的帮助弹窗应先处理 Esc/?、暂停图片快捷键，并在关闭时恢复焦点。
